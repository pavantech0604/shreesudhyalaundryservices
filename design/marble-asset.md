# Marble background asset

Generated using the built-in imagegen tool. The original rectangular logo was supplied as a material/colour reference, not as artwork to reproduce. The selected output was visually inspected, copied into the project non-destructively, and encoded to WebP for delivery. The original logos were not modified.

- Source output: local source retained outside the shipping/public directory
- Web asset: `public/images/brand-marble-v2.webp` (60,224 bytes)
- Consuming styles: `src/app/brand.css`

Final generation prompt:

> Use case: photorealistic-natural. Asset type: premium website full-page marble background texture. Image 1 is ONLY a material and colour reference, not a logo to reproduce. Create a large landscape seamless-looking flat scanned marble texture matching the warm ivory marble INSIDE the attached Shree Sudhya logo. Preserve its softly cloudy off-white/ivory stone, warm champagne beige shadowing, wispy meandering grey-beige mineral veins and occasional delicate muted gold veins. Make the natural marble visible across the entire image, moderately more discernible than in the reference so it remains visible behind web content at normal scale. Balanced warm ivory base #F5F0E7 with lighter #FAF7F1 areas and a few beige #D8C8AC veins. Avoid pure white empty regions. Flat orthographic top-down surface with uniform soft illumination; no perspective, no objects, no lettering, no logos, no symbols, no border, no gold rectangular frame, no watermarks. It must be a genuine organic photographic-looking marble surface, not straight diagonal lines or a geometric pattern. Wide landscape texture.

This is a logo-inspired generated texture, not an exact pixel extraction of the original marble. It deliberately makes the original material character more visible at website scale.
